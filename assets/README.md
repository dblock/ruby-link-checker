# Logo

The ruby-link-checker logo is a faceted ruby with a white checkmark. Its colors come from the [Ruby logo](https://www.ruby-lang.org/images/header-ruby-logo.svg) (`#fcb19d`, `#e62923`, `#e2242a`, `#cf251f`, `#b8211c`, `#9e0c00`), with `#e2242a` as the main red. It was designed by Claude (AI) for @dblock and is licensed with the project under the [MIT License](../LICENSE.md).

| File | Use |
|------|-----|
| [logo.svg](logo.svg) | The gem with a checkmark, for avatars, favicons, and small sizes. |
| [wordmark.svg](wordmark.svg) | The gem and the project name, for light backgrounds. |
| [wordmark-dark.svg](wordmark-dark.svg) | The gem and the project name, for dark backgrounds. |
| [wordmark-source.svg](wordmark-source.svg) | The editable wordmark, with live text that requires the Inter font. |

All files are generated by [logo.rb](logo.rb), which defines the gem's facets, colors, and wordmark layout. The wordmark text is set in [Inter](https://github.com/rsms/inter) Bold (v4.1), licensed under the [SIL Open Font License 1.1](https://github.com/rsms/inter/blob/master/LICENSE.txt), and converted to outlines so that it renders without the font. To change the logo, edit `logo.rb` and regenerate the files with `Inter-Bold.ttf` from an Inter release; the script installs [ttfunk](https://github.com/prawnpdf/ttfunk) with `bundler/inline`.

```
ruby assets/logo.rb path/to/Inter-Bold.ttf
```

The assets are excluded from the gem package.
